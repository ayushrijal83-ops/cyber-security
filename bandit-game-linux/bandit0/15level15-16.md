## <span style="font-size: 24px">Bandit Level 15 → 16</span>

**<span style="font-size: 24px">The challenge:</span>**<span style="font-size: 24px"> The password for Level 16 can be retrieved by submitting the current level's password to </span>**<span style="font-size: 24px">port 30001 on localhost using SSL/TLS encryption</span>**<span style="font-size: 24px">.</span>

**<span style="font-size: 24px">Password for Level 16:</span>**<span style="font-size: 24px"> </span>`kS0Hf0u5HiXFwKMKFqXvPdOTNGGa0X8V`

---

## <span style="font-size: 24px">What I Learned: SSL/TLS</span>

<span style="font-size: 24px">SSL/TLS is a protocol that </span>**<span style="font-size: 24px">encrypts</span>**<span style="font-size: 24px"> data traveling between client and server. Plain </span>`nc`<span style="font-size: 24px"> sends data in cleartext — anyone listening can read it. With SSL, the data is encrypted before it's sent.</span>

<span style="font-size: 24px">The previous level (port 30000) used plain text, so </span>`nc`<span style="font-size: 24px"> worked. This level (port 30001) requires SSL, so </span>`nc`<span style="font-size: 24px"> alone won't work.</span>

---

## <span style="font-size: 24px">The Command I Used</span>

<span style="font-family: Menlo, Monaco, Consolas, Cascadia Mono, Ubuntu Mono, DejaVu Sans Mono, Liberation Mono, JetBrains Mono, Fira Code, Cousine, Roboto Mono, Courier New, Courier, sans-serif, system-ui; color: rgb(15, 17, 21); font-size: 24px">text</span>

```
openssl s_client -connect localhost:30001
```

## <span style="font-size: 24px">The Lesson</span>

<span style="font-size: 24px">Not every port speaks plain text. Some require SSL/TLS encryption. When a level says "SSL encryption," switch from </span>`nc`<span style="font-size: 24px"> to </span>`openssl s_client`<span style="font-size: 24px">.</span>
