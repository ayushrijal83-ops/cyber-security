## <span style="font-size: 24px">New Command: </span>`nc`<span style="font-size: 24px"> (netcat)</span>

`nc`<span style="font-size: 24px"> = </span>**<span style="font-size: 24px">netcat</span>**<span style="font-size: 24px">. It's the Swiss Army knife of networking. It lets you:</span>

- <span style="font-size: 24px">Connect to a port</span>

- <span style="font-size: 24px">Send data to a service</span>

- <span style="font-size: 24px">Listen on a port</span>

- <span style="font-size: 24px">Transfer files</span>

- <span style="font-size: 24px">Create reverse shells (later in your journey)</span>

<span style="font-size: 24px">For this level, we used it as a simple client:</span>

<span style="font-family: Menlo, Monaco, Consolas, Cascadia Mono, Ubuntu Mono, DejaVu Sans Mono, Liberation Mono, JetBrains Mono, Fira Code, Cousine, Roboto Mono, Courier New, Courier, sans-serif, system-ui; color: rgb(15, 17, 21); font-size: 24px">text</span>

```
nc localhost 30000
```

## <span style="font-size: 24px">Important: </span>`localhost`<span style="font-size: 24px"> vs </span>`exit`

<span style="font-size: 24px">You wrote: </span>*<span style="font-size: 24px">"which mean we cannot use exit."</span>*

<span style="font-size: 24px">That's a small misunderstanding. </span>`localhost`<span style="font-size: 24px"> means "this same machine" — the Bandit server. It doesn't mean you can't use </span>`exit`<span style="font-size: 24px"> to log out. It means the service is running </span>**<span style="font-size: 24px">on the same server</span>**<span style="font-size: 24px">, not on an external machine.</span>

<span style="font-size: 24px">In this level:</span>

- <span style="font-size: 24px">You are </span>`bandit14`<span style="font-size: 24px"> on the Bandit server</span>

- <span style="font-size: 24px">There's a service running on the Bandit server at port 30000</span>

- <span style="font-size: 24px">You connect to it via </span>`localhost`<span style="font-size: 24px"> (same machine)</span>

## <span style="font-size: 24px">Alternative One-Liner</span>

<span style="font-size: 24px">Instead of running </span>`nc`<span style="font-size: 24px"> and pasting manually, you can pipe the password directly:</span>

<span style="font-family: Menlo, Monaco, Consolas, Cascadia Mono, Ubuntu Mono, DejaVu Sans Mono, Liberation Mono, JetBrains Mono, Fira Code, Cousine, Roboto Mono, Courier New, Courier, sans-serif, system-ui; color: rgb(15, 17, 21); font-size: 24px">text</span>

```
cat /etc/bandit_pass/bandit14 | nc localhost 30000
```

<span style="font-size: 24px">This reads the password and sends it straight to the service.</span>

---

## <span style="font-size: 24px">The Lesson</span>

<span style="font-size: 24px">Network services listen on ports. If a service is running on the same machine you're on, you can talk to it via </span>`localhost`<span style="font-size: 24px">. </span>`nc`<span style="font-size: 24px"> is the simplest way to do that.</span>

<span style="font-size: 24px">This is a </span>**<span style="font-size: 24px">huge</span>**<span style="font-size: 24px"> skill — in real pentesting, you'll constantly find services running on ports that accept input and return data. </span>`nc`<span style="font-size: 24px"> is how you talk to them.</span>
