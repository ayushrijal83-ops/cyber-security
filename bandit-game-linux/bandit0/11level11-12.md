## <span style="font-size: 24px">What is ROT13?</span>

<span style="font-size: 24px">ROT13 is a simple cipher. Every letter shifts </span>**<span style="font-size: 24px">13 positions forward</span>**<span style="font-size: 24px"> in the alphabet.</span>

<span style="font-family: Menlo, Monaco, Consolas, Cascadia Mono, Ubuntu Mono, DejaVu Sans Mono, Liberation Mono, JetBrains Mono, Fira Code, Cousine, Roboto Mono, Courier New, Courier, sans-serif, system-ui; color: rgb(15, 17, 21); font-size: 24px">text</span>

```
A → N
B → O
C → P
...
M → Z
N → A
O → B
...
Z → M
```

<span style="font-size: 24px">Same for lowercase: </span>`a → n`<span style="font-size: 24px">, </span>`b → o`<span style="font-size: 24px">, etc.</span>

<span style="font-size: 24px">Because 13 is exactly half of 26, applying ROT13 twice gives you back the original text. Encoding and decoding are the same operation.</span>

## <span style="font-size: 24px">The </span>`tr`<span style="font-size: 24px"> command</span>

`tr`<span style="font-size: 24px"> = </span>**<span style="font-size: 24px">translate</span>**<span style="font-size: 24px">. It replaces characters from SET1 with characters from SET2, position by position.</span>

<span style="font-family: Menlo, Monaco, Consolas, Cascadia Mono, Ubuntu Mono, DejaVu Sans Mono, Liberation Mono, JetBrains Mono, Fira Code, Cousine, Roboto Mono, Courier New, Courier, sans-serif, system-ui; color: rgb(15, 17, 21); font-size: 24px">text</span>

```
tr 'SET1' 'SET2'
```

<span style="font-size: 24px">Example:</span>

<span style="font-family: Menlo, Monaco, Consolas, Cascadia Mono, Ubuntu Mono, DejaVu Sans Mono, Liberation Mono, JetBrains Mono, Fira Code, Cousine, Roboto Mono, Courier New, Courier, sans-serif, system-ui; color: rgb(15, 17, 21); font-size: 24px">text</span>

```
echo "abc" | tr 'abc' 'xyz'
```

<span style="font-size: 24px">Output:</span>

<span style="font-family: Menlo, Monaco, Consolas, Cascadia Mono, Ubuntu Mono, DejaVu Sans Mono, Liberation Mono, JetBrains Mono, Fira Code, Cousine, Roboto Mono, Courier New, Courier, sans-serif, system-ui; color: rgb(15, 17, 21); font-size: 24px">text</span>

```
xyz
```

<span style="font-size: 24px">Because </span>`a → x`<span style="font-size: 24px">, </span>`b → y`<span style="font-size: 24px">, </span>`c → z`<span style="font-size: 24px">.</span>

## <span style="font-size: 24px">Breaking down the ROT13 command</span>

<span style="font-family: Menlo, Monaco, Consolas, Cascadia Mono, Ubuntu Mono, DejaVu Sans Mono, Liberation Mono, JetBrains Mono, Fira Code, Cousine, Roboto Mono, Courier New, Courier, sans-serif, system-ui; color: rgb(15, 17, 21); font-size: 24px">text</span>

```
cat data.txt | tr 'A-Za-z' 'N-ZA-Mn-za-m'
```

**<span style="font-size: 24px">SET1:</span>** `A-Za-z`

- <span style="font-size: 24px">All uppercase: </span>`ABCDEFGHIJKLMNOPQRSTUVWXYZ`

- <span style="font-size: 24px">All lowercase: </span>`abcdefghijklmnopqrstuvwxyz`

**<span style="font-size: 24px">SET2:</span>** `N-ZA-Mn-za-m`

- `N-Z`<span style="font-size: 24px"> = </span>`NOPQRSTUVWXYZ`

- `A-M`<span style="font-size: 24px"> = </span>`ABCDEFGHIJKLM`

- `n-z`<span style="font-size: 24px"> = </span>`nopqrstuvwxyz`

- `a-m`<span style="font-size: 24px"> = </span>`abcdefghijklm`

<span style="font-size: 24px">So the full rotated alphabet is:</span>

- <span style="font-size: 24px">Uppercase: </span>`NOPQRSTUVWXYZABCDEFGHIJKLM`

- <span style="font-size: 24px">Lowercase: </span>`nopqrstuvwxyzabcdefghijklm`

<span style="font-size: 24px">Every letter in SET1 maps to the letter 13 positions ahead in SET2.</span>

## <span style="font-size: 24px">The lesson</span>

<span style="font-size: 24px">ROT13 is not encryption — it's a simple substitution cipher. But it shows up constantly in CTFs and even some real-world obfuscation. </span>`tr`<span style="font-size: 24px"> is the classic Linux tool for character-by-character substitution.</span>
