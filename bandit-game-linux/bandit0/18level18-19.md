## <span style="font-size: 24px">Level 18 → 19</span>

**<span style="font-size: 24px">Challenge:</span>**<span style="font-size: 24px"> SSH into </span>`bandit18`<span style="font-size: 24px"> — but </span>`.bashrc`<span style="font-size: 24px"> has been modified to log you out immediately upon connection.</span>

**<span style="font-size: 24px">The Problem:</span>**<span style="font-size: 24px"> Normal SSH connection triggers </span>`.bashrc`<span style="font-size: 24px">, which prints "Byebye!" and closes the connection.</span>

**<span style="font-size: 24px">The Fix:</span>**<span style="font-size: 24px"> Run commands directly with SSH instead of getting an interactive shell:</span>

<span style="font-family: Menlo, Monaco, Consolas, Cascadia Mono, Ubuntu Mono, DejaVu Sans Mono, Liberation Mono, JetBrains Mono, Fira Code, Cousine, Roboto Mono, Courier New, Courier, sans-serif, system-ui; color: rgb(15, 17, 21); font-size: 24px">text</span>

```
ssh bandit18@bandit.labs.overthewire.org -p 2220 "ls"
```

<span style="font-size: 24px">Output:</span>

<span style="font-family: Menlo, Monaco, Consolas, Cascadia Mono, Ubuntu Mono, DejaVu Sans Mono, Liberation Mono, JetBrains Mono, Fira Code, Cousine, Roboto Mono, Courier New, Courier, sans-serif, system-ui; color: rgb(15, 17, 21); font-size: 24px">text</span>

```
readme
```

<span style="font-size: 24px">Then:</span>

<span style="font-family: Menlo, Monaco, Consolas, Cascadia Mono, Ubuntu Mono, DejaVu Sans Mono, Liberation Mono, JetBrains Mono, Fira Code, Cousine, Roboto Mono, Courier New, Courier, sans-serif, system-ui; color: rgb(15, 17, 21); font-size: 24px">text</span>

```
ssh bandit18@bandit.labs.overthewire.org -p 2220 "cat readme"
```

<span style="font-size: 24px">Output:</span>

<span style="font-family: Menlo, Monaco, Consolas, Cascadia Mono, Ubuntu Mono, DejaVu Sans Mono, Liberation Mono, JetBrains Mono, Fira Code, Cousine, Roboto Mono, Courier New, Courier, sans-serif, system-ui; color: rgb(15, 17, 21); font-size: 24px">text</span>

```
KpsOfPkcP7i1FlIExk2QEjyt6dw8dxZI
```

<span style="font-size: 24px">The </span>`.bashrc`<span style="font-size: 24px"> trick only affects </span>**<span style="font-size: 24px">interactive</span>**<span style="font-size: 24px"> logins. Passing a command as an argument bypasses it entirely.</span>

## <span style="font-size: 24px">The Lesson</span>

<span style="font-size: 24px">When a server kicks you out immediately, don't panic. Run your command directly:</span>

<span style="font-family: Menlo, Monaco, Consolas, Cascadia Mono, Ubuntu Mono, DejaVu Sans Mono, Liberation Mono, JetBrains Mono, Fira Code, Cousine, Roboto Mono, Courier New, Courier, sans-serif, system-ui; color: rgb(15, 17, 21); font-size: 24px">text</span>

```
ssh user@host "command"
```

<span style="font-size: 24px">This is also useful in real pentesting for:</span>

- <span style="font-size: 24px">Running a single command without leaving a shell history</span>

- <span style="font-size: 24px">Bypassing interactive login restrictions</span>

- <span style="font-size: 24px">Automating tasks across multiple servers</span>
