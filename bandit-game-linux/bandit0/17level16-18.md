# <span style="font-size: 24px">Bandit Level 17 → 18</span>

**<span style="font-size: 24px">Password for Level 18:</span>**<span style="font-size: 24px"> </span>`OQxXZjELndr90zuhOTDYBEomI0SZITXI`

---

## <span style="font-size: 24px">The Challenge</span>

<span style="font-size: 24px">The password for Level 18 is in </span>`passwords.new`<span style="font-size: 24px">, but it's not as simple as reading the file. There are two files:</span>

- `passwords.new`

- `passwords.old`

<span style="font-size: 24px">The password is the </span>**<span style="font-size: 24px">line that changed</span>**<span style="font-size: 24px"> between the two files.</span>

---

## <span style="font-size: 24px">What I Did</span>

### <span style="font-size: 24px">Step 1: List the files</span>

<span style="font-family: Menlo, Monaco, Consolas, Cascadia Mono, Ubuntu Mono, DejaVu Sans Mono, Liberation Mono, JetBrains Mono, Fira Code, Cousine, Roboto Mono, Courier New, Courier, sans-serif, system-ui; color: rgb(15, 17, 21); font-size: 24px">text</span>

```
ls
```

<span style="font-size: 24px">Output:</span>

<span style="font-family: Menlo, Monaco, Consolas, Cascadia Mono, Ubuntu Mono, DejaVu Sans Mono, Liberation Mono, JetBrains Mono, Fira Code, Cousine, Roboto Mono, Courier New, Courier, sans-serif, system-ui; color: rgb(15, 17, 21); font-size: 24px">text</span>

```
passwords.new  passwords.old
```

### <span style="font-size: 24px">Step 2: Compare the two files</span>

<span style="font-family: Menlo, Monaco, Consolas, Cascadia Mono, Ubuntu Mono, DejaVu Sans Mono, Liberation Mono, JetBrains Mono, Fira Code, Cousine, Roboto Mono, Courier New, Courier, sans-serif, system-ui; color: rgb(15, 17, 21); font-size: 24px">text</span>

```
diff passwords.new passwords.old
```

<span style="font-size: 24px">Output:</span>

<span style="font-family: Menlo, Monaco, Consolas, Cascadia Mono, Ubuntu Mono, DejaVu Sans Mono, Liberation Mono, JetBrains Mono, Fira Code, Cousine, Roboto Mono, Courier New, Courier, sans-serif, system-ui; color: rgb(15, 17, 21); font-size: 24px">text</span>

```
42c42
< OQxXZjELndr90zuhOTDYBEomI0SZITXI
---
> qOg5pVOjPx9x9VccyYBADiT4xxyoUB8D
```

<span style="font-size: 24px">The line with </span>`<`<span style="font-size: 24px"> is in </span>`passwords.new`<span style="font-size: 24px"> but not in </span>`passwords.old`<span style="font-size: 24px">. That's the password.</span>

### <span style="font-size: 24px">Step 3: Get more context (optional)</span>

<span style="font-family: Menlo, Monaco, Consolas, Cascadia Mono, Ubuntu Mono, DejaVu Sans Mono, Liberation Mono, JetBrains Mono, Fira Code, Cousine, Roboto Mono, Courier New, Courier, sans-serif, system-ui; color: rgb(15, 17, 21); font-size: 24px">text</span>

```
diff -u passwords.new passwords.old
```

<span style="font-size: 24px">This shows a unified diff with surrounding lines for better understanding.</span>

## <span style="font-size: 24px">The Lesson</span>

`diff`<span style="font-size: 24px"> is the standard Linux tool for comparing files. In this case, finding the one line that changed between two password lists revealed the answer instantly. It's also useful for:</span>

- <span style="font-size: 24px">Finding config file changes</span>

- <span style="font-size: 24px">Comparing code versions</span>

- <span style="font-size: 24px">Spotting what changed between backups</span>

- <span style="font-size: 24px">Verifying file integrity</span>
